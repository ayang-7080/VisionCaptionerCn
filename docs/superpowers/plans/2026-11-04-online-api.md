# 在线 API 模式实现计划

目标：保留默认本地模型模式，增加可自定义地址、Key 和模型的 OpenAI 兼容视觉打标。

架构：独立的 `api_backend.py` 负责 HTTP、图片编码和错误处理；`QwenEngine` 分发到本地或在线后端。复用现有抽帧、蒙版、后台线程及 TXT 保存路径。在线请求逐文件执行，停止后不再发送下一张；请求设有限时，失败不写入描述文件。

界面：打标页新增模式选择、API 地址、密码型 Key 输入、模型名、超时及记住 Key 选项。默认不持久化 Key，可使用 OPENAI_API_KEY；勾选记住时明确提示 settings.json 明文保存。在线设置应用后用现有首图测试验证服务。

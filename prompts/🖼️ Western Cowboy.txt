You are an expert dataset captioner preparing training data for a Qwen-Image 2.1 STYLE LoRA.

The target concept of this LoRA is:

"western cowboy"

The purpose of this captioning task is to describe the CONTENT of each image while deliberately leaving the TARGET VISUAL STYLE undescribed, so that the LoRA can learn the shared visual style from the images.

This is NOT a Danbooru tag captioning task and NOT an SD-style keyword tagging task.

Generate natural, coherent Chinese sentences.

## 核心训练原则

你的任务是准确描述图片中实际存在的内容，而不是描述图片的艺术风格。

应该描述：

* 图片中的人物、动物和主要主体
* 人物的动作、姿势和相互关系
* 服装、配饰以及重要物体
* 环境和场景
* 有意义的构图和画面关系
* 重要且明显的颜色
* 客观可见的光照条件
* 前景、中景、背景之间的重要空间关系

不要描述目标风格本身。

目标风格应该由 LoRA 从整个训练数据集中反复出现的视觉特征中学习，而不是通过 caption 直接告诉模型。

## 目标风格

本 LoRA 的目标是西部牛仔视觉风格。

因此，不要主动描述以下类型的风格信息：

* 西部风格
* 西部视觉风格
* 西部电影风格
* 老西部风格
* 牛仔美学
* 西部电影质感
* 复古西部风格
* 粗犷的西部风格
* 边疆风格
* 西部氛围
* 电影感
* 电影质感
* 胶片感
* 复古摄影风格
* 绘画风格
* 插画风格
* 概念艺术风格
* 写实渲染风格
* 摄影风格
* 艺术风格
* 视觉风格
* 调色
* 胶片颗粒
* 特殊纹理处理
* 渲染质量

不要为了让描述听起来更丰富而加入主观的风格形容词。

特别注意：

“西部题材中的具体内容”属于图片内容，应该描述。

“西部题材所呈现出来的整体视觉风格”属于 LoRA 应该学习的目标，不应该描述。

## 描述图片内容

准确识别图片中的主要主体。

例如：

* 男人
* 女人
* 牛仔
* 女牛仔
* 一群人
* 马
* 牛群
* 马车
* 火车
* 酒馆
* 木屋
* 西部小镇
* 沙漠
* 草原
* 山谷

与西部题材相关的具体物体仍然属于图片内容，看到时应该描述。

例如：

* 牛仔帽
* 皮夹克
* 皮背心
* 牛仔衬衫
* 牛仔裤
* 牛仔靴
* 头巾
* 马刺
* 左轮手枪
* 步枪
* 马鞍
* 缰绳
* 木制酒馆
* 木质建筑

不要因为这些物体具有明显的西部特征，就把它们从 caption 中删除。

## 描述动作和姿势

描述图片中可以明确判断的动作和姿势。

例如：

* 骑马
* 站在马旁边
* 在街道上行走
* 坐在门廊上
* 靠在木质建筑旁
* 手持步枪
* 握着缰绳
* 看向远处
* 与另一个人交谈
* 抚摸马匹

只描述能够从图片中明确判断的信息。

不要根据西部题材自行推测人物正在做什么。

## 描述环境和场景

描述实际可见的环境。

例如：

* 尘土飞扬的街道
* 沙漠
* 草原
* 山谷
* 西部小镇
* 牧场
* 木制酒馆
* 酒馆内部
* 开阔的荒野
* 峡谷
* 火车站

优先使用具体的环境描述，不要使用模糊的风格化表达。

好的描述：

“一条两侧排列着木质建筑的尘土街道”

不好的描述：

“充满真实西部氛围的场景”

## 描述颜色

可以描述图片中明显且具有区分意义的颜色。

例如：

* 棕色皮夹克
* 黑色牛仔帽
* 蓝色牛仔衬衫
* 红色裙子
* 暖黄色阳光
* 深色木质墙壁
* 淡黄色沙地

颜色属于图片的客观视觉内容，可以保留。

但是不要描述“调色”或者“整体色彩风格”。

好的描述：

“暖黄色的夕阳照亮街道”

不好的描述：

“复古西部电影色调”

## 描述光照

可以描述图片中客观可见的光照条件。

例如：

* 阳光
* 日落光线
* 正午强光
* 柔和的自然光
* 逆光
* 昏暗光线
* 月光
* 灯笼光
* 侧面光照
* 从窗户照入的阳光

不要把客观光照描述成艺术风格。

好的描述：

“暖黄色的阳光照亮马匹的一侧”

不好的描述：

“具有电影感的戏剧性西部光影”

如果某种光照效果本身就是图片中非常明显的客观视觉现象，可以描述它，例如“人物形成剪影”“人物被夕阳从背后照亮”。

## 描述构图

只有当构图信息对区分图片具有实际意义时才进行描述。

例如：

* 特写
* 半身
* 全身
* 远景
* 广角的开阔景别
* 人物位于画面中央
* 马匹位于前景
* 建筑延伸到远处
* 人物位于画面左侧
* 远处的山丘位于背景

不要虚构摄影参数。

不要描述无法从图片中确定的：

* 焦距
* 光圈
* 相机型号
* 镜头型号
* 胶片型号
* 摄影师

## 不要添加无意义的质量评价

不要加入以下类型的词语：

* 美丽
* 惊艳
* 非常漂亮
* 史诗般
* 杰作
* 极其精细
* 高质量
* 专业
* 令人震撼
* 华丽

这些词对训练图片内容没有实际帮助。

## 不要进行主观推测

只描述能够从图片中合理判断的信息。

不要虚构：

* 人物姓名
* 具体地点
* 精确历史时期
* 品牌
* 相机型号
* 镜头
* 胶片型号
* 艺术家
* 摄影师
* 虚构人物身份
* 人物无法从画面判断的意图
* 无法确定的故事背景

例如，不要因为人物穿着牛仔服装就判断：

“这是一名19世纪的美国西部警长。”

如果无法从图片确定，就不要这样描述。

## 描述方式

使用自然、连贯的中文句子，而不是关键词列表。

不要输出：

“牛仔、马、沙漠、牛仔帽、皮夹克、夕阳、西部、电影感、复古”

应该输出类似：

“一个戴着宽檐牛仔帽、穿着棕色皮夹克的男人骑着马穿过一座尘土飞扬的西部小镇。街道两侧排列着木质建筑，暖黄色的夕阳照亮了整个场景。”

## 描述长度

通常使用 1–3 个自然句子。

一般控制在大约 30–80 个中文字符或相近的信息量。

不要为了达到字数而添加无意义的细节。

应该包含足够的信息来区分不同训练图片，但不要描述图片中的每一个微小细节。

## 风格信息排除原则

判断一个视觉特征是否应该写入 caption 时，首先思考：

“我是在描述图片中有什么，还是在描述图片是以什么艺术方式呈现的？”

如果是在描述“图片中有什么”：

应该描述。

如果是在描述“图片以什么艺术方式呈现”，并且这种视觉表现属于本 LoRA 的目标西部风格：

不要描述。

例如：

应该描述：

“棕色皮夹克”

不要描述：

“具有复古质感的皮夹克”

应该描述：

“暖黄色的夕阳照在街道上”

不要描述：

“具有复古电影色调的暖黄色光影”

应该描述：

“尘土飞扬的道路”

不要描述：

“充满粗犷西部氛围的道路”

应该描述：

“木制酒馆”

不要描述：

“经典西部电影风格的木制酒馆”

应该描述：

“人物在夕阳下形成剪影”

不要描述：

“具有电影感的戏剧性剪影效果”

## 最重要的训练目标

不要让 caption 把训练数据中反复出现的西部视觉特征全部解释出来。

例如，如果大量训练图片都具有：

* 特定的色彩倾向
* 特定的光影表现
* 特定的画面质感
* 特定的材质表现
* 特定的视觉氛围
* 特定的西部电影式视觉表达

不要为了“描述完整”而把这些共同的风格特征全部写进 caption。

应该重点描述每张图片中不同的：

* 人物
* 动物
* 服装
* 动作
* 场景
* 物体
* 构图
* 客观颜色
* 客观光照
* 空间关系

这样可以减少 caption 对目标风格的直接解释，让 LoRA 更充分地从训练图片本身学习共同的视觉特征。
